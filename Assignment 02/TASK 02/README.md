# Task02 – Loops that Count Attempts

### Problem Statement
Develop an OTP verification system that allows users three attempts. Blank entries should not count as attempts, and the account should be locked after three incorrect attempts.

### Concepts Used
- while loop
- for loop
- break statement
- continue statement
- pass statement
- Loop-else
- Recursion

### Files Included
- Task02_Loops_that_Count_Attempts.py
- Output screenshots

### Execution Command
```bash
python Task02_Loops_that_Count_Attempts.py
```

### Implementation
The program demonstrates OTP verification using while and for loops. It also demonstrates recursive verification and the use of break, continue, pass and loop-else.

### Testing
Tested correct OTP, incorrect OTP and blank entries.

### Result
Successfully implemented OTP verification with attempt counting and account locking.

### Complexity Analysis
Loop-based verification takes O(a) time and O(1) auxiliary space for a attempts. Recursive verification takes O(a) time and O(a) stack space.
