# Task01 – Decisions with Many Boundaries

### Problem Statement
Develop a Python program to determine household electricity subsidy eligibility based on electricity consumption, ration card availability and elderly family members.

### Concepts Used
- if statements
- if-else statements
- if-elif-else statements
- Nested if
- Boolean conditions
- Chained comparisons

### Files Included
- Task01_Decisions_with_Many_Boundaries.py
- Output screenshots

### Execution Command
```bash
python Task01_Decisions_with_Many_Boundaries.py
```

### Implementation
The program implements electricity subsidy eligibility using separate if statements and if-elif-else conditions.

### Testing
Tested eight different households, including boundary values of 100, 101, 200 and 201 electricity units.

### Result
Successfully implemented and compared different decision-making structures to determine subsidy eligibility.

### Complexity Analysis
The decision-making process takes O(1) time and O(1) auxiliary space for a fixed number of conditions.
