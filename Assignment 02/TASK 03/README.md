# Task03 – Vehicle Registration Number Validator

### Problem Statement
Develop a Python program to normalise, validate and format vehicle registration numbers using string operations without regular expressions.

### Concepts Used
- String indexing
- String slicing
- upper()
- replace()
- strip()
- isalpha()
- isdigit()
- String immutability
- Functions

### Files Included
- Task03_Vehicle_Registration_Validator.py
- Output screenshots

### Execution Command
```bash
python Task03_Vehicle_Registration_Validator.py
```

### Implementation
The program removes spaces and hyphens, converts registration numbers into uppercase and checks their validity using string methods and slicing.

### Testing
Tested valid and invalid vehicle registration numbers, including different input formats.

### Result
Successfully implemented vehicle registration normalisation, validation and receipt formatting.

### Complexity Analysis
Normalisation and validation take O(L) time, where L is the length of the registration number.
