# Task05 – Functions, Parameters and Scope

### Problem Statement
Develop a college canteen order system using Python functions and demonstrate the behaviour of parameters and variable scope.

### Concepts Used
- Functions
- Positional parameters
- Keyword parameters
- Default parameters
- Return values
- Local variables
- Global variables
- Nonlocal variables
- Mutable default arguments
- Closures

### Files Included
- Task05_Functions_Parameters_and_Scope.py
- Output screenshots

### Execution Command
```bash
python Task05_Functions_Parameters_and_Scope.py
```

### Implementation
The program demonstrates the mutable default argument problem and its correction using None. It also demonstrates independent customer orders, multiple return values and variable scope.

### Testing
Tested the buggy and corrected functions with multiple customer orders.

### Result
Successfully implemented functions with independent order lists and demonstrated different parameter and scope concepts.

### Complexity Analysis
Adding an item to a list takes O(1) amortised time. Space complexity is O(m) for an order containing m items.
